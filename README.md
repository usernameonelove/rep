# My Progress — PWA

Приложение для отслеживания личных целей.

## Возможности
- любое количество целей;
- текущий прогресс / целевое значение;
- общий процент;
- выбор целей для главного экрана;
- редактирование и удаление;
- локальное хранение данных;
- экспорт / импорт JSON;
- работа офлайн после первого открытия;
- установка на iPhone как PWA.

## Запуск через GitHub Pages
1. Создай новый публичный GitHub repository.
2. Загрузи все файлы и папку `icons`.
3. В репозитории открой **Settings → Pages**.
4. В `Build and deployment` выбери `Deploy from a branch`.
5. Branch: `main`, folder: `/ (root)`.
6. Сохрани. GitHub выдаст ссылку вида:
   `https://ТВОЙ-USERNAME.github.io/ИМЯ-РЕПОЗИТОРИЯ/`
7. Открой её в Safari на iPhone.
8. Нажми «Поделиться» → «На экран Домой».

Данные целей сохраняются в localStorage конкретного браузера/устройства. Для переноса используй Настройки → Экспортировать данные.
